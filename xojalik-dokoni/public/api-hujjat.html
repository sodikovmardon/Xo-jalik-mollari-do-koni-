API v1

Ochiq JSON API hujjati

Tashqi ilovalar (masalan, qurilish kalkulyatori) ushbu API orqali mahsulotlar, narxlar va ombordagi qoldiqlar haqidagi ma'lumotlarni real vaqt rejimida olishi mumkin. Autentifikatsiya talab qilinmaydi, CORS yoqilgan.

Bazaviy manzil: http://localhost:3000/api/v1

GET /products GET /products/:id GET /categories POST /orders POST /orders/bulk
GET /api/v1/products

Barcha mahsulotlar ro'yxatini qaytaradi. Ixtiyoriy filtrlar qo'llab-quvvatlanadi.

Query parametrlari

ParametrTavsif
categoryKategoriya nomi bo'yicha filtr (masalan ?category=Sement)
searchNomi/tavsif/kategoriya bo'yicha qidiruv (masalan ?search=silikat)

Namuna so'rov

GET /api/v1/products?category=Sement

GET /api/v1/categories

Do'kondagi barcha noyob kategoriyalar ro'yxatini qaytaradi.

{
  "success": true,
  "count": 7,
  "data": ["Asbob-uskunalar", "Bo'yoq materiallari", "Elektr materiallari", "G'isht", "Qum", "Santexnika", "Sement"]

POST /api/v1/orders

Mijoz nomidan yakka buyurtma so'rovi yaratadi.

So'rov tanasi (JSON)

MaydonTavsif
product_idMahsulot ID raqami (majburiy)
mijoz_ismiMijoz ismi (majburiy)
telefonTelefon raqami (majburiy)
miqdorBuyurtma miqdori (majburiy)

Namuna so'rov

POST /api/v1/orders
Content-Type: application/json

{
  "product_id": 2,
  "mijoz_ismi": "Ali Valiyev",
  "telefon": "+998901234567",
  "miqdor": 20
}

Namuna javob

{
  "success": true,
  "message": "Buyurtmangiz qabul qilindi",
  "data": { "order_id": 7 }
}
POST /api/v1/orders/bulk

Savatdagi bir nechta mahsulotlarni bitta so'rovda buyurtma qilish.

So'rov tanasi (JSON)

MaydonTavsif
mijoz_ismiMijoz ismi (majburiy)
telefonTelefon raqami (majburiy)
itemsMahsulotlar massivi: [{ "product_id": 1, "miqdor": 2 }, ...]

Namuna so'rov

POST /api/v1/orders/bulk
Content-Type: application/json

{
  "mijoz_ismi": "Aziz Karimov",
  "telefon": "+998901234567",
  "items": [
    { "product_id": 1, "miqdor": 100 },
    { "product_id": 4, "miqdor": 1 }
  ]
}

Namuna javob

{
  "success": true,
  "message": "Buyurtmalaringiz qabul qilindi",
  "data": { "order_ids": [8, 9] }
}

Eslatma: real vaqtli ma'lumot

Keshlash qo'llanilmaydi — admin panelda narx yoki ombordagi soni o'zgartirilishi bilanoq, GET /api/v1/products so'rovi yangilangan qiymatlarni qaytaradi.
